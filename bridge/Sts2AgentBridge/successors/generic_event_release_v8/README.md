# Generic event release v8: off-screen test

A separate experiment derived from release v7. It preserves the G7 protocol and
all gameplay sources except a transform adapter that allows selection only when
the holder, card and hitbox are fully below a validated clipping ancestor.
Complete original coverage, stable references, deferred input checks and the
selected-only transformation journal remain required. This does not implement
scrolling or general off-screen support.

See the [contract](../../../../docs/PHASE_1_GENERIC_EVENT_RELEASE_V8_CONTRACT.md).
Use the standalone checker with Python3.10+, SDK9.0.303, pinned cached references
and a new /private/tmp scratch directory. Offline execution uses inert target
objects only; production compilation is never production execution.

All 29 predecessors stay frozen. No launch until offline acceptance, fresh
stopped/closed/clean-base checks, exact owned installation and verification.
The live fixture is Aroma of Chaos at its untouched two initial choices on
Profile3 with enough ordinary cards for a fully clipped allocated row. The
native eligibility proof chooses the card; deck count alone is not proof.

One authenticated client invocation uses a fresh installed-state hash and
retains G7 choose:0 followed by first_legal policy. Success requires exact card
child completion and parent continuation. Normal quit and exact transactional
cleanup close the campaign; no retries or historical-state reuse.
