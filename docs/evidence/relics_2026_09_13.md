## Implemented boundaries

- Every audited ID has an explicit immutable definition and rule path. Ordinary
  generated Act 1 rewards/treasure and shops use the expanded eligible pools;
  authored scenarios retain explicit smaller pools. Old Coin and The Courier
  cannot appear in merchant stock.
- Combat relic records are owned copies of persistent run inventory. Counters
  synchronize back after actions; combat-only trigger memory resets per fight.
  Hook modules separate entry/turns, plays/exhausts and damage. Damage and block
  modifiers share the authoritative card/creature paths.
- Acquisition uses plain pending records with owned IDs, candidate lists and
  generated offers. Nested pickup choices retain the granting room and finish
  before queued follow-up cards/relics. Room entry is blocked until completion.
  Invalid acquisition restores resources, RNG, inventory and identity allocators.
- Shop discounts combine before final truncation; purchases capture the paid
  price before pickup changes. Courier restocks with a fresh offer identity.
  Permanent card additions share Egg/Fresnel, Book of Five Rings and Lucky Fysh
  effects, including event transformations and hatching.
- Rest hooks include Lift, Dig, Miniature Tent, healing/max HP and potion rewards.
  Rewards include Prayer Wheel, White Star, Lava Rock and persisted upgrade/
  enchantment offers. Silver Crucible consumes reward uses on generation and
  leaves the first treasure empty. Juzu and Winged Boots modify unknown-room
  outcomes and non-edge travel using owned history.
- Added supporting content: seven relic enchantments, Injury, Eternal Greed,
  Neow's Fury and targeted 15-damage Potion-Shaped Rock.
- Private schemas are combat **v10** and run **v20**. Restore checks owned relic
  records, per-relic transient fields, counters, choices and resumable enemy hits.
  Public fixtures, encoders and bridge contracts are unchanged.

## Review and regression findings

One independent semantic reviewer inspected the inventory, pinned pickup/turn
semantics, combat interruptions and run acquisition/persistence. Corrected cases
include invalid/missing restored relic counters, an enemy cursor skipping hits,
an attacker killed during a draw choice acting again, Frail/Vambrace rounding,
skippable restored Neow's Bones rewards, undrained automatic pickup work,
pending acquisition permitting combat, zero-card Shears damage and lethal Leafy
Poultice. The final bounded review reported no remaining blockers.

Additional ordering probes restored JSON at a Centennial Puzzle interruption:
Puzzle before Demon Tongue pauses before healing, and reversing inventory order
heals first; Puzzle before Bronze Scales pauses before retaliation, and reversing
order can kill the attacker first. Remaining hits do not execute after its death.
Existing Eye With Teeth revival remains a legal non-attack enemy turn. Opening
relic damage that ends combat now transfers directly into rewards.

## Remaining content and fidelity work

**160 relics are obtainable with the default catalog.** Kaleidoscope's rule is
implemented and tested with injected foreign catalogs, but default acquisition
rejects before mutation because those character card pools are absent. The test
uses explicit synthetic foreign definitions; it does not claim those characters
have been implemented.

Potion-producing relics use the configured supported potion pool (Fire/Block by
default); Potion-Shaped Rock is an explicit token. Neow's Bones uses the supported
modifier-curse subset, Clumsy/Injury. Full potion/curse catalogs, native rarity
weights and cross-source grab-bag depletion remain content/generation tasks.
Named owned Python RNG streams provide deterministic continuation, not native
seed/draw-order parity. The existing Neow start still exposes its fixed supported
positive choices; this change implements the other pickup rules without claiming
native offer construction, unlock progression or all granting events. Acts 2/3,
other characters, ascensions and exhaustive interaction/differential evidence
remain outside this solo A0 Act 1 implementation.
