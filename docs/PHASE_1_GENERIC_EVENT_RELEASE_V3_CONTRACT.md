One per-adapter cached enum is published when a parent-native Capture completes.
It denotes the first failed/waiting predicate, or the completed parent/child/map
capture state. Child construction cannot overwrite it. A getter reads only this
cached field. Capture preparation passes an out-code through existing checks;
constructors discard that code. A core timeout or action with no new Capture may
retain an earlier code. It is diagnostic history, not proof of the current
response's cause, callback completion or successful gameplay effects.

## Same-response transport

The new Runtime.Create accepts an optional Func<GenericEventDiagnosticCode>,
defaulting to NotCaptured for inert consumers. Production owns a per-runtime,
once-bound concrete adapter target, separate from cleanup-transfer locals. The
provider reads only its cached field and is cleared after successful owner-frame
service disposal. Preserve all failed-construction and retained-cleanup paths.
Immediately after service.Handle, in that same owner-frame queue operation,
sample the provider once and copy the enum with the response body through both
OwnedServiceResponse and OwnedByteDispatchResult. Workers never read the native
provider. Provider exceptions or invalid enum values become DiagnosticUnavailable
without changing valid gameplay JSON. Detached, timed-out or stopped queue results
cannot leak or overwrite another response's code.

Encode exactly one required X-Sts2-Native-Diagnostic HTTP response header using
the finite mapping. Preserve body bytes, routes, authentication, lineage, limits
and terminal classification. Python validates exact header order/allowlist,
canonical lengths, full body, EOF, successful close, deadlines and reentry before
recording the code. It returns the original body to the unchanged host. Append
last_response_diagnostic to the bounded final summary: initially none, then the
last fully received transport-validated response's code. Later incomplete or
invalid exchanges preserve that previous code. HTTP validation does not imply
host semantic acceptance: even a later rejected JSON body may carry a completed
transport diagnostic. No second JSON validator or duplicated host semantics.
