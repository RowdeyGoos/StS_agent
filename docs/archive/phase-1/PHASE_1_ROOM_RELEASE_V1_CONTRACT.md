    {"schema_version":"room_flows_v1_transport_config_v1","enabled":true,"flow_kind":"shop","bind_address":"127.0.0.1","port":43117,"token_file":"credential.hex"}
    {"schema_version":"room_flows_v1_transport_config_v1","enabled":true,"flow_kind":"event","bind_address":"127.0.0.1","port":43117,"token_file":"credential.hex"}

Missing, disabled, malformed or extra-field configurations fail closed before credential read, random nonce generation, service creation or socket bind. The one authoritative parser yields RoomFlowSelection.Shop or Event from protected bytes. Runtime Create consumes configuration and credential arrays, generates one nonce and invokes exactly one owner-frame factory with (selection, nonce). A returned service is runtime-owned; factory failure retains responsibility for partially constructed objects. No surface inference, selection override or fallback exists. The bootstrap five-second deadline bounds only pre-first-frame credential transfer; it ends on successful Start and does not expire the listener during manual navigation. Port 43117 is exclusive. Existing item/old/new operator, overlay and campaign units must be absent before install; never adopt or modify predecessor units.

## Wire and uncertainty boundary

Exactly four routes: parent GET /probe/room-flows-v1/public/decision and POST /probe/room-flows-v1/public/action; event child GET /probe/item-v1/public/item-decision and POST /probe/item-v1/public/item-action. Shop rejects child routes. Parent body cap 65536 bytes; child cap 4096 bytes. Request head cap 4096; preserve canonical ordered ASCII HTTP, fixed loopback/port, fixed bearer credential, half-close/EOF, header/write/connection bounds and silent failure. Pre-authentication remains 32 requests/second with burst 16; authentication uses 20 requests/second with burst 16 to admit the combined event-child sequence. The Python exchange spaces request starts by at least 50 ms across parent and child, within the existing deadlines, so a full bounded continuation does not exhaust the burst solely through rapid valid transitions. One authenticated exchange is in flight across GET and POST until response send and socket cleanup finish. Competing authenticated traffic is terminal and cannot reach the service. Reserve POST identities and lifetime budgets before rate/queue work; never refund or retry. Maximum parent attempts: shop 3, event 12; event child attempts 1; total GETs 1024. Duplicate, budget, queue or delivery uncertainty stops the runtime, with no reconstructed receipt. The service supplies every response body. Parent complete/resolved and failure/error results are terminal; child resolved alone is not parent terminal. A terminal body must finish its send attempt before lifecycle stop becomes visible.

Adapt the owned frame queue to cap 65536 and additionally enforce the route body limit. Exact-link the two generic transport kernels; the frozen queue references its old 4096 limit and is not reused unchanged. Test-only APIs use conditional compilation and are absent from the production candidate. Pure runtime fixtures exercise actual frozen RoomFlowWireService and sessions with synthetic adapters, including reservations, cross-request concurrency, lost/partial receipt, late-byte zeroing and owner cleanup. Test listeners use ephemeral loopback only and reject production port 43117.
