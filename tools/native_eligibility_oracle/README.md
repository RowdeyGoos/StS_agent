# Native acquisition eligibility oracle

Run from the repository root with .NET 9 and the pinned 0.107.1 assembly. The
program checks its SHA-256 before loading it, resolves DLLs only from the supplied
dependency directory, and reads the checked-in relic scope fixture.

```sh
dotnet build tools/native_eligibility_oracle/oracle.csproj --artifacts-path /tmp/sts-eligibility-oracle
dotnet /tmp/sts-eligibility-oracle/bin/oracle/debug/oracle.dll /path/to/sts2.dll /path/to/dependencies > /tmp/native-eligibility.json
```

The oracle registers canonical content models and supplies an explicit in-memory
`IRunState` proxy. Its only supported reads are player list, total floor and solo
card constraint; any other context access throws. A constructor-free Player
contains only the declared character, unlock state and proxy reference needed by
these methods. This is a controlled method fixture, not a running native game.
No RunManager, lobby, game launch, profile, save, history or Cloud access occurs.

Actual native methods provide:

- All 161 scoped relic predicates at floors 0/40/41 and run counts 0/9999, plus
  shop and Neow predicate ownership metadata.
- All-unlocked solo card/relic/potion pool order, with each relevant epoch's
  exclusions obtained by removing that epoch from an otherwise unlocked context.
- Eight bag sequences (four seeds at two floor boundaries), each with nine
  front/back/filtered/fallback pulls, shared/player bags, RNG counter and suffix.
- Six Dingy Rug contexts: marked reward, direct grant, pool changes blocked,
  custom pool, already-colorless pool and rare-only marked reward.
- Eight potion batches with blacklists and combat eligibility, including distinct
  initial picks, exact RNG consumption and suffixes.

The checked-in [fixture](../../tests/fixtures/headless_runtime_eligibility_vectors.json)
retains the output with compact records. Expected values are not generated by the
Python implementation. Tests of Lasting Candy and White Star additionally use
inspected factory call/flag semantics; those full reward hooks are not executed by
this oracle. The combat oracle’s [reward-edges mode](../native_combat_oracle/README.md#duplicate-reward-option-oracle) now checks Lasting Candy’s native fallback and physical modifiers. Unlock gates are inventoried here; gameplay remains the declared
all-unlocked solo Ironclad Act 1 profile.
